# ServiceNow-Project-Corporate-Gifting-App
The Corporate Gifting is a custom-built Application developed on the ServiceNow platform using **App Engine Studio**. The application enables managers to recognize and reward employees by issuing digital E-Vouchers that are credited to an employee’s E-Wallet. Employees can redeem vouchers based on their wallet balance and voucher eligibility.

The solution demonstrates ServiceNow development including **table creation, catalog items, workflows, client scripts, UI Policies, dashboards, and UI configuration**.

🚀 Steps to Import the Application (XML / Update Set) into ServiceNow
- Login to ServiceNow instance.
- Navigate to **System Update Sets → Retrieved Update Sets**.
- Click **Import Update Set from XML**.
- Upload the provided XML / Update Set file from this repository.
- Once uploaded, open the update set record.
- Click **Preview Update Set** and resolve any preview problems if prompted.
- Click **Commit Update Set** to install the application.
- Navigate to the application module (Corporate Gifting App) from the Application Navigator to view and test the functionality.
- Navigate to Service catalog to order E-Vouchers and raise requests using the Catalog Item and Record Producer.
